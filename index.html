Rclone

A personal-use Google Drive integration operated by eosforge, using the open-source rclone application.

It allows the owner to upload, download, list and synchronize selected files between their own devices and Google Drive. When configured with rclone crypt, file contents are encrypted before uploading and decrypted locally when downloading.

This website provides information only. It does not provide a login service or accept files, passwords or access tokens. This is not an official Google or rclone project.
